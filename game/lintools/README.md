# LinTools 文字特效

适用于 Ren'Py 8.5+。将整个 `lintools` 目录复制到目标项目的 `game/` 下，重启游戏即可自动注册。没有第三方依赖，不需要修改 say screen 或 Character。

本项目点击“开始游戏”会进入特效总览，可滚动查看全部效果与标签写法；点击“逐句演示”进入普通对白示例。演示脚本是 `game/script.rpy`，复用库时不需要复制它。

总览下方的“破碎 / 鼠标演示”可直接查看两种交互效果。

总览只保留彩虹、组合、躲开鼠标、破碎四项，每项显示标题、效果和完整标签原文。破碎标题右侧的“重播”按钮只重置该项动画，不重置滚动位置。

```renpy
e "普通文字 {ltshake}抖动{/ltshake} 普通文字"
e "{ltwave=8}波浪{/ltwave}"
e "{lttornado=radius=7;speed=1.2}绕圈{/lttornado}"
e "{ltrainbow=speed=0.25;spread=0.08}彩虹{/ltrainbow}"
e "{ltfx=wave:amplitude=7;speed=1|rainbow:speed=0.3}组合{/ltfx}"
e "{size=44}{b}{ltwave=5}原生字号与粗体{/ltwave}{/b}{/size}"
```

## 参数

所有参数可省略。多个参数用分号 `;` 分隔；只写一个数字时设置下表第一个参数。

| 标签 / 组合中的名称 | 参数与默认值 | 含义 |
| --- | --- | --- |
| `ltshake` / `shake` | `amplitude=3;speed=20` | 每轴最大偏移像素；每秒更换偏移的次数 |
| `ltwave` / `wave` | `amplitude=6;speed=1.5;wavelength=12` | 振幅像素；每秒周期数；一个波长的字符数 |
| `lttornado` / `tornado` | `radius=6;speed=1.5;spread=0.12` | 绕圈半径像素；每秒圈数；相邻字符相位差（圈） |
| `ltrainbow` / `rainbow` | `speed=0.25;spread=0.08;saturation=0.85` | 每秒色相圈数；相邻字符色相差；饱和度 |

位移/半径范围 0–100，shake 频率 0–120，其他 speed 0–20，wavelength 1–200，spread 和 saturation 0–1。非法数值、未知参数、重复参数会报错，不执行参数中的 Python 表达式。

## 组合与排版

- 多效果用 `{ltfx=wave|rainbow}...{/ltfx}`；各效果参数跟在 `:` 后。同一效果不能重复。效果标签不能互相嵌套，也不能在里面嵌套原生 `{shader}`，以避免内层 Shader 覆盖外层效果。
- `{size}`、`{b}`、`{i}`、`{color}` 可与效果标签嵌套。彩虹接管正文颜色，保留描边/阴影颜色；外层 `{color}` 不会给彩虹再染色。
- 使用引擎的字体、换行和逐字显示逻辑，不拆字为独立 Displayable。动画在文字显示完后持续运行。
- 位移动画不参与布局，请给大幅度效果留足行距和边缘空间，如 `what_line_spacing=16`。标签不会自动扩展文本框。
- `{w}`、`{p}`、`{nw}`、`{fast}` 建议放在特效标签外，分段使用效果标签。
- 可用于 screen 的 `text`、按钮和角色姓名，不局限于对白。字号与字体来自宿主项目。
- 动画使用渲染时钟，读档或回滚后不保证恢复到同一动画相位。历史记录是否保留效果由宿主项目的 history screen 决定。

## 接入细节

库使用命名 store `lintools_text` 与 `lintools.*` Shader 名；标签重名时报告冲突。初始化优先级 100 时，如果 `config.default_textshader` 为 `None`，会设置为 `typewriter`，让同一 Text 内的普通文字也进入 Shader 排版。宿主已指定的默认 Shader 会保留。不要在更晚的初始化中把默认 Shader 重新设回 `None`。

删除库前先移除剧本中的自定义标签；Ren'Py 生成的 `.rpyc` 也应随对应脚本移除。

## 破碎：从末字到首字，完成后自动下一句

```renpy
# 整句直接完整显示，从末字开始短暂微颤后崩开，无需先重复普通对白。
e "{ltshatter=hold=0;stagger=0.1;duration=1.2;pieces=4;distance=28;gravity=180}那些未曾说出口的话，终于碎在了风里。{/ltshatter}"
e "文字碎完后会自动进入这一句。"
```

`ltshatter` 将整句直接完整显示，默认不等待、不逐字打字，立即从最后一个可见字符向前依次播放“逐渐加剧的颤抖 → 崩开”：每字先保持完整字形颤抖 0.3 秒，幅度系数从 0.5 线性提升到 1，默认水平幅度由 2 像素提升到 4 像素；抖动频率为水平方向 4.75 Hz、垂直方向 6.625 Hz，较前版减半。颤抖末尾不减弱，随后立即沿 Voronoi（沃罗诺伊）分区崩开；需要额外停留时仍可显式设置 `hold`。默认每字随机分成 3–5 个较大的不规则块，保留原字形的笔画、颜色和描边。碎块保持原尺寸，向外四散、持续旋转，并受重力加速下坠；每块另有一个任意方向的小初始冲量，不切成小方格或缩小。初始冲量只决定该块的初速度，不逐帧改变方向；重力和碎片运动从崩开时开始计时。崩开阶段前 35% 打开裂缝，最后 25% 淡出。空格与换行不占碎裂顺序。默认参数：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `hold` | 0 | 开始微颤前保持完整静止的秒数，范围 0–30；默认显示后立即开始 |
| `stagger` | 0.09 | 相邻字启动微颤的间隔秒数，范围 0.01–3；崩开也保持同样的顺序和间隔 |
| `tremble` | 0.3 | 每字崩开前的微颤时长，范围 0–1 秒；0 为跳过微颤 |
| `tremble_distance` | 4 | 微颤的最大水平偏移，范围 0–10 像素；实际幅度从该值的 50% 逐渐提升到 100%，垂直幅度为水平的 60%，0 为关闭位移 |
| `duration` | 0.9 | 单个字崩开并淡出的秒数，范围 0.05–10；不包含前置微颤 |
| `distance` | 28 | 单字动画期间向外四散的位移基准，范围 0–200 像素；每块的方向、幅度略有不同 |
| `gravity` | 180 | 下坠加速度，范围 0–2000 像素/秒²；0 为关闭重力，下坠位移为 `0.5 * gravity * 已碎裂秒数²` |
| `impulse` | 48 | 额外随机初始冲量的速度基准，范围 0–100 像素/秒；方向覆盖整圈，每块速度为该值的 50%–100%，0 为关闭 |
| `pieces` | 4 | 每字的 Voronoi 分块数基准，整数 2–8；实际数量由 `variation` 浮动 |
| `variation` | 1 | 分块数的随机浮动幅度，整数 0–3，实际数量限制在 2–8；默认 `pieces=4;variation=1` 为每字 3–5 块，0 为固定数量 |
| `rotation` | 3 | 每块最大旋转角度，范围 0–45 度；0 为保持朝向 |
| `gap` | 0.6 | 分区边界额外打开的裂缝宽度，范围 0–8 像素；0 为仅靠位移与旋转分离 |
| `auto` | 1 | 完成后自动继续对白；设置 0 则等用户点击 |
| `style` | default | 内部文字使用的 Ren'Py 文字样式名称 |

旧标签写法和 `pieces=2` 至 `pieces=8` 仍可使用，但 `pieces` 的含义由“每轴方格数”改为“每字总分块数基准”：旧的 `pieces=4` 现在默认得到 3–5 个大块，而非 16 个小方块；需要固定 4 块时加 `variation=0`。`distance=28` 恢复为默认四散幅度；如需轻微裂开，可改为 3–8 并设置 `gravity=0;impulse=0`。分块数量、分区和飞散差异由字符与分块位置确定，不逐帧随机变化，也不消耗游戏随机数；重播会重建整段 Text 和计时，并沿相同裂纹重新播放。

只想让字形沿裂纹错开、保持碎块朝向时，可使用 `{ltshatter=pieces=3;distance=4;gravity=0;impulse=0;rotation=0;gap=0.8}...{/ltshatter}`。字号与字体仍应通过标签内部的 `{size}`、`{font}` 或 `style` 设置。这些参数的像素值不会随字号自动缩放。重力会让碎块持续向下移动，使用时请在文字下方预留空间；总览已为破碎项增加下坠展示区域。

完整时长为 `hold + (可见字符数 - 1) * stagger + tremble + duration`。多个破碎片段会等待当前对白中所有启用 auto 的片段完成。自动推进只针对标准 `say` screen 中 `id="what"` 的当前对白，screen 文本、总览和历史记录不触发推进。不在预测或标签解析阶段改变剧情。用户仍可点击提前继续或使用快进。

## 躲开鼠标

```renpy
e "{ltrepel=radius=110;distance=18;response=12}把鼠标靠近这段文字，它就会向远处躲开。{/ltrepel}"
e "{ltrepel}{size=40}{color=#75dccb}颜色、字号标签写在效果内部。{/color}{/size}{/ltrepel}"
```

鼠标进入影响范围后，每个字独立朝远离鼠标的方向移动；越近斥力越强，鼠标移远后平滑归位。不会吞掉点击、滚轮或键盘事件。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `radius` | 110 | 影响半径，范围 1–600 像素 |
| `distance` | 18 | 最大偏移，范围 0–100 像素 |
| `response` | 12 | 跟随速度，越小越柔和，范围 0.1–60 |
| `style` | default | 内部文字使用的 Ren'Py 文字样式名称 |

### 两个新标签的排版约定

这两个效果位于 `interactive_effects.rpy`，使用逐字嵌入 Displayable，以便切割真实字形与接收局部鼠标坐标。它们与前面的 Shader 标签有以下区别：

- 内容立即完整显示，不逐字打字；破碎默认显示后立即开始极短微颤，再崩开，无需先显示一次普通对白。
- 内部文字默认用宿主的 `default` 样式，不能自动继承外层 Text 或 Character 的所有文字属性。自定义字体、字号、粗体、颜色应写在标签内部，或传入 `style=你的文字样式`。中文字体沿用本项目的 default 样式。
- 支持内部 `b/i/u/s/plain/size/font/color/alpha/outlinecolor/k/kerning` 标签。不要嵌套其他特效、图片、超链接、ruby 或对白控制标签；`{w}`、`{nw}` 等放在外面。
- 保留基本换行，但逐字渲染不适用于需要跨字连写、复杂字形塑形或精确字偶距的文本。组合附加符号、变体选择符和常见 ZWJ 序列尽量作为整体处理。
- 偏移和碎片不扩展排版尺寸，需要为行距和边缘预留空间。总览中的破碎可用标题右侧的“重播”按钮重新播放，也可用“破碎 / 鼠标演示”重看对白流程。
- 不加入 `ltfx` 的 Shader 组合列表。自动推进适用于标准 ADV 对白；自定义 say screen 名称、NVL 或其他剧情交互需要项目自行接入。

实现依据：[文字 Shader](https://www.renpy.org/doc/html/textshaders.html)、[自定义文本标签](https://www.renpy.org/doc/html/custom_text_tags.html)。

## 帘幕：细绳串字与鼠标拨动

总览底部点击“帘幕 →”打开独立展示界面；“复位”使所有绳子与文字回到初始位置，返回总览或按 Esc 退出该界面。

文字逐格排布，每个字符占一个正方形格子。推荐使用全角文字和全角空格 `　` 保持原文对齐。每一列是一条独立细绳：顶部连续空白跳过，从该列第一个非空字符上方固定，往下串联到最后一个非空字符；中间空格保留绳段，不显示字。整列为空时不生成细绳。不支持制表符。

鼠标划过细绳时，会根据移动速度、方向及与绳子的距离施加冲量；绳段约束将力量传给上下文字，重力与阻尼使它们晃动并逐渐停下。检测整段鼠标移动轨迹，快速划过多列也能拨动它们。鼠标静止不会持续施力。

每格默认细分为 8 段真实物理绳段（64 像素格距时每段 8 像素），顶部半格也相应细分；空格处保持同样密度。细分节点独立运动、参与重力与约束，文字挂在对应格点的物理节点上并随绳摆动。轻绳节点与较重的文字节点配合弱弯曲约束，使字间绳段能够连续弯曲；分层限长约束帮助长绳传递张力，允许绳段弯曲和松弛。鼠标冲量平滑分布到接触点附近，文字朝向取周围绳段的平均方向。物理步长固定为 1/120 秒，每步进行 10 轮张力求解。

推荐在 screen 中使用独立 Displayable，避免把大块多行内容塞进对白框：

```renpy
screen my_curtain():
    default curtain = lintools_text.CurtainText(
        "　春风又绿\n江南山水间\n　等你归来", cell=64, size=42,
        strength=0.65, subdivisions=8)
    add curtain align (0.5, 0.5)
    textbutton "复位" action Function(curtain.reset)
```

也自动注册了 `{ltcurtain}` 标签，适合 screen 的 text：

```renpy
text "{ltcurtain=cell=64;size=42;strength=0.65;subdivisions=8}　春风又绿\n江南山水间\n　等你归来{/ltcurtain}"
```

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `cell` | 64 | 方格边长，24–160 像素 |
| `subdivisions` | 8 | 每格的实际物理绳段数，整数 2–16；顶部半格使用向上取整的一半段数。越大越细腻，计算开销也随节点数增加；一般使用 8，大量长绳可降至 4–6 |
| `size` | 42 | 字号，12–120 |
| `strength` | 0.65 | 鼠标拨动力度，0–3，0 为禁用拨动 |
| `damping` | 2 | 阻尼，0.1–12，越大越快停下 |
| `radius` | 20 | 鼠标与绳子的接触范围，1–100 像素 |
| `gravity` | 1100 | 重力，100–4000 像素/秒² |
| `margin` | 80 | 四周预留摆动空间，20–240 像素 |
| `style` | default | 内部字形的文字样式 |

`CurtainText` 另可传 `color` 和 `rope_color` 设置字体、绳子颜色。不要在帘幕标签内部嵌套其他标签；字体来自 `style`，字号通过 `size` 配置。帘幕维持固定网格尺寸，不按外层 text 的宽度自动换行；请显式写入换行并为摆动留足空间。复用时连同 `text_effects.rpy` 与 `interactive_effects.rpy` 一起复制整个 `lintools` 文件夹。
